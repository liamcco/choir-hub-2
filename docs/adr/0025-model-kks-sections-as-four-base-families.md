# Model KK Sections as four base families

Kammarkören (KK) has four domain Sections—KKS, KKA, KKT, and KKB—while its singers are described by the finer-grained numbered Voices within those Sections, such as KKB1. MK and DK retain their existing fine-grained Section topology. KK Voice Parents therefore scope directly to one of the four KK Sections; temporary Event Voice assignments and numbered Voice changes do not change a singer's Home Choir Section, except that a numbered change creates a new dated Section Placement.

This asymmetric model reflects the real organizational terminology: KK's Voice Parents are responsible for the four base-family Sections, while singers still need numbered designations for placement and musical participation.
