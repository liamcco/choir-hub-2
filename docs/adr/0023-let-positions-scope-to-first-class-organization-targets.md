# Let Positions scope to first-class organization targets

CSK Choir Hub will allow a Position Scope to reference CSK, a Choir, a Section, or a Group directly. A Position may have multiple Scopes where one office genuinely spans several targets, but Choirs and Sections will not be recreated as Groups merely to support Position scoping.

This supports organization-wide officers, choir-specific offices, Voice Parents, and committee or Board roles with the same Position model. Position Assignment Eligibility is a set of topology-defined requirements evaluated when an Assignment starts and combined by one top-level `all` or `any` mode; nested boolean expressions are not part of the model, and later changes do not invalidate an existing Assignment. A Choir Position Scope implicitly requires matching Choir Membership, and a Section Position Scope implicitly requires current Section Placement; these scope-derived requirements are not duplicated as explicit declarations and are always mandatory. Positions normally have at most one Choir or Section scope; if multiple such scopes ever exist, matching any one scoped Choir or Section is sufficient. Explicit requirements may inspect Member Status or Voice Capability. Member Status is a mandatory baseline: it defaults to Active and Passive, may be stated as Active only, or may be stated as Former allowed, which permits Active, Passive, and Former. A Voice Capability requirement may name one or more accepted Voices; matching any one is sufficient. A named base Voice matches any explicit fine Voice in that category, while a named fine Voice matches exactly. Conductor Positions are Choir-scoped without a Section scope, so they require Choir Membership but not Section Placement. Group-scoped Position Assignments also supply the dated effective Group Membership established in ADR-0024.
